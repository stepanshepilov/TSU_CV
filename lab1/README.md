## Теория

### Изображение как данные

Цифровое изображение — матрица пикселей. Полутоновое хранится как массив `(H, W)` со значениями `0…255`, цветное — как `(H, W, 3)`. OpenCV читает цветное изображение в порядке каналов **BGR**, а не RGB, поэтому перед выводом через Matplotlib каналы переставляются:

```python
image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
```

Обращение `image[y, x]` возвращает вектор из трёх чисел `uint8` — сначала строка, потом столбец. Это противоположно порядку `(x, y)`, принятому в функциях рисования OpenCV.

### Полутоновое преобразование

Яркость — взвешенная сумма каналов:

$$Y = 0.299\,R + 0.587\,G + 0.114\,B.$$

Коэффициенты отражают неодинаковую чувствительность глаза к красному, зелёному и синему. Та же формула используется для канала $Y$ модели YCrCb, поэтому в задаче 9 оба результата совпадают с точностью до округления.

### Бинаризация методом Оцу

Метод перебирает все пороги $t \in [0, 255]$ и выбирает тот, который максимизирует межклассовую дисперсию:

$$\sigma_b^2(t) = w_0(t)\,w_1(t)\,[\mu_0(t) - \mu_1(t)]^2,$$

где $w_0, w_1$ — доли пикселей двух классов, $\mu_0, \mu_1$ — их средние яркости. Максимум $\sigma_b^2$ эквивалентен минимуму суммарной внутриклассовой дисперсии: порог разводит «фон» и «объект» максимально далеко друг от друга. В OpenCV:

```python
otsu_threshold, binary = cv2.threshold(
    image, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU
)
```

Порог `0` означает «подобрать автоматически»; найденное значение возвращается первым.

### Модель HSV

Цвет описывается тоном $H$, насыщенностью $S$ и яркостью $V$. В OpenCV $H$ хранится в диапазоне `0…179` — это угол на цветовом круге, делённый на 2, чтобы поместиться в один байт; $S$ и $V$ — в диапазоне `0…255`.

Практическая ценность модели в том, что информация о самом цвете сосредоточена в одном канале. В BGR смена освещения меняет все три значения сразу, поэтому выделять объект по цвету неудобно. В HSV достаточно ограничить $H$ и отсечь слишком тёмные и блёклые пиксели по $S$ и $V$:

```python
yellow_mask = cv2.inRange(hsv, np.array([26, 80, 80]), np.array([35, 255, 255]))
```

### Расшифровка цветовых обозначений

| Модель | Канал | Расшифровка | Диапазон OpenCV (`uint8`) |
|---|---|---|---|
| BGR | `B` | Blue — синий | `0…255` |
| BGR | `G` | Green — зелёный | `0…255` |
| BGR | `R` | Red — красный | `0…255` |
| HSV | `H` | Hue — оттенок цвета | `0…179` |
| HSV | `S` | Saturation — насыщенность | `0…255` |
| HSV | `V` | Value — яркость | `0…255` |
| HLS | `H` | Hue — оттенок цвета | `0…179` |
| HLS | `L` | Lightness — светлота | `0…255` |
| HLS | `S` | Saturation — насыщенность | `0…255` |
| YCrCb | `Y` | яркость изображения | `0…255` |
| YCrCb | `Cr` | красная цветоразность | `0…255`, нейтральный центр около `128` |
| YCrCb | `Cb` | синяя цветоразность | `0…255`, нейтральный центр около `128` |
| LAB | `L` | Lightness — светлота | `0…255` |
| LAB | `a` | ось зелёный ↔ красный | `0…255`, нейтральный центр около `128` |
| LAB | `b` | ось синий ↔ жёлтый | `0…255`, нейтральный центр около `128` |

В OpenCV цветное изображение обычно хранится в порядке `BGR`, а не `RGB`. В моделях `YCrCb` и `LAB` центральное значение около `128` у цветоразностных каналов означает отсутствие выраженного смещения по соответствующей цветовой оси.

### Альфа-канал

Формат RGBA добавляет четвёртый канал непрозрачности: 0 — пиксель полностью прозрачен, 255 — полностью непрозрачен. При наложении на фон работает формула $C = \alpha F + (1-\alpha) B$. Альфа-канал поддерживают PNG и TIFF, но не JPEG. Читать такой файл нужно с флагом `cv2.IMREAD_UNCHANGED` — обычный `cv2.imread` вернёт только три канала.

## Ответы на контрольные вопросы

1. **Что такое пиксель и как он представлен в цветном изображении?** Пиксель — наименьший элемент растрового изображения. В цветном изображении он представлен вектором из трёх чисел `uint8`, в OpenCV — в порядке B, G, R. Обращение `image[y, x]` возвращает именно такой вектор.
2. **В чём разница между RGB и HSV?** RGB задаёт цвет смесью трёх первичных излучений и удобен для вывода на экран, но информация о цвете размазана по всем трём каналам: при смене освещения меняются все три значения. HSV разделяет цвет и яркость — $H$ отвечает за оттенок, $S$ за насыщенность, $V$ за яркость, поэтому выделять объекты по цвету удобнее именно в HSV. В OpenCV $H$ лежит в диапазоне 0–179.
3. **Как получить отдельный цветовой канал в OpenCV?** Через `b, g, r = cv2.split(image)` либо срезом NumPy `image[:, :, 0]` — второй способ быстрее, так как не копирует данные. Обратная сборка — `cv2.merge([b, g, r])`.
4. **Как преобразовать цветное изображение в градации серого?** `gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)`; внутри считается $Y = 0.299R + 0.587G + 0.114B$. Альтернатива — читать файл сразу флагом `cv2.IMREAD_GRAYSCALE`.
5. **Что такое альфа-канал?** Четвёртый канал, задающий непрозрачность каждого пикселя: 0 — прозрачно, 255 — непрозрачно. Поддерживается PNG и TIFF, не поддерживается JPEG; в OpenCV читается только с флагом `cv2.IMREAD_UNCHANGED`.
