## Теория

### Классификация

Классификация сопоставляет входному объекту одну метку из конечного набора классов. Для изображения классификатор получает матрицу яркостей и возвращает наиболее вероятный вид одежды.

Основные этапы:

1. загрузить и проверить данные;
2. привести пиксели к диапазону `0…1`;
3. разделить данные на обучение и тест;
4. обучить модель;
5. получить предсказания;
6. вычислить метрики и изучить ошибки.

### SVM

SVM ищет разделяющую гиперплоскость с максимальным зазором между классами. Для многоклассового режима обучается набор бинарных классификаторов. В работе используется `LinearSVC`, потому что изображение после разворачивания имеет `784` признака, а линейная модель позволяет получить быстрый и понятный базовый результат.

Перед SVM изображение преобразуется из формы `(28, 28)` в вектор `(784,)`:

```python
X_train = x_train.reshape(TRAIN_SIZE, -1)
X_test = x_test.reshape(TEST_SIZE, -1)
svm_model = LinearSVC(C=1.0, dual='auto', max_iter=2000)
svm_model.fit(X_train, y_train)
```

Параметр `C` управляет компромиссом между шириной зазора и штрафом за ошибки. Большой `C` сильнее подгоняет обучение, маленький допускает больше ошибок ради более простой границы.

### CNN

CNN сохраняет двумерную структуру изображения. Свёрточный слой применяет небольшие ядра к локальным областям и учится находить края, текстуры и части объектов. `MaxPool2d` уменьшает пространственный размер и делает признаки устойчивее к небольшим сдвигам. После свёрток карта признаков разворачивается и передаётся полносвязным слоям.

Архитектура ноутбука:

```text
Conv2d(1 -> 32, 3x3) -> ReLU -> MaxPool(2)
Conv2d(32 -> 64, 3x3) -> ReLU -> MaxPool(2)
Flatten -> Linear(64*7*7 -> 128) -> ReLU -> Linear(128 -> 10)
```

Для многоклассовой классификации используется `CrossEntropyLoss`. Она принимает сырые logits, поэтому в последнем слое не нужен `softmax`.

### L2-регуляризация

L2-регуляризация добавляет к функции потерь штраф за большие веса:

$$L_{total}=L_{classification}+\lambda\sum_i w_i^2.$$

В PyTorch она включается параметром `weight_decay` оптимизатора:

```python
optimizer = torch.optim.Adam(
    model.parameters(), lr=1e-3, weight_decay=1e-4
)
```

Такая регуляризация ограничивает сложность модели плавно: веса не обнуляются принудительно, но большие значения становятся менее выгодными.

### Dropout

Dropout во время обучения случайно зануляет часть активаций. В ноутбуке используется `p=0.5`:

```python
nn.Dropout(0.5)
```

На этапе оценки Dropout автоматически выключается методом `model.eval()`. Это важно: сравнивать accuracy нужно в режиме оценки, а не во время случайного зануления нейронов.

### Метрики

Accuracy:

$$Accuracy=\frac{TP+TN}{TP+TN+FP+FN}.$$

Для многоклассовой задачи эта формула означает долю всех правильно классифицированных изображений. Accuracy удобна при примерно сбалансированных классах, как в Fashion-MNIST.

Precision показывает, какая доля объектов, предсказанных классом, действительно относится к этому классу. Recall показывает, какую долю объектов настоящего класса модель нашла. F1-score — гармоническое среднее Precision и Recall.

### Confusion matrix

Матрица ошибок — таблица, где строки соответствуют истинным классам, а столбцы — предсказанным. Большие значения на диагонали означают правильную классификацию. Вне диагонали видны пары классов, которые модель путает. Для одежды типичны ошибки между `Shirt`, `T-shirt/top`, `Pullover` и `Coat`, потому что их силуэты похожи.

## Разбор ноутбука

### 1. Импорты и воспроизводимость

Фиксируются `numpy`- и `torch`-seed `42`, ограничивается число CPU-потоков, выбирается устройство `cuda`, если оно доступно, иначе используется CPU.

### 2. Загрузка IDX

Fashion-MNIST хранится в бинарном IDX-формате. Функция `read_idx` читает magic number, размерность и shape из заголовка через `struct`, а затем преобразует байты в массив `uint8`. Нормализация выполняется делением на `255.0`.

### 3. SVM

SVM обучается на `10000` векторов пикселей и оценивается на `2000` тестовых примерах. Время измеряется через `time.perf_counter`, а accuracy — функцией `accuracy_score`.

### 4. CNN

`TensorDataset` хранит тензоры, а `DataLoader` формирует мини-батчи размера `128`. Один шаг обучения состоит из прямого прохода, вычисления CrossEntropyLoss, `backward()` и обновления Adam.

### 5. Регуляризация

Обучаются две дополнительные модели с одинаковой архитектурой и двумя эпохами:

- CNN + L2: `weight_decay=1e-4`;
- CNN + Dropout: `Dropout(0.5)`.

Так сравнивается именно способ регуляризации, а не архитектура.

### 6. Матрицы ошибок

Для L2-модели и Dropout-модели вызываются `confusion_matrix`, после чего две таблицы выводятся рядом через `seaborn.heatmap`. Чем темнее диагональ и светлее вне диагонали, тем лучше модель различает классы.

## Фактические результаты запуска

Запуск выполнен на CPU, на подмножестве `10000/2000`, по 2 эпохи для каждой CNN:

| Модель | Accuracy |
|---|---:|
| Linear SVM | 0.8190 |
| Базовая CNN | 0.8255 |
| CNN + L2 | 0.7840 |
| CNN + Dropout | 0.8080 |

В этом коротком учебном запуске базовая CNN получила лучший результат. L2 и Dropout обучались всего две эпохи и на ограниченной выборке, поэтому меньшая accuracy не означает, что регуляризация бесполезна: её цель — улучшить обобщение и уменьшить переобучение при сопоставимом режиме обучения. Для честного промышленного сравнения следует увеличить выборку и число эпох, а также повторить обучение с несколькими seed.

## Ответы на контрольные вопросы

1. **Что такое задача классификации изображений?** Это определение класса, к которому относится входное изображение, например вида одежды.
2. **Разница между kNN, SVM и Random Forest?** kNN хранит обучающие объекты и голосует по ближайшим; SVM строит разделяющую границу с максимальным зазором; Random Forest объединяет предсказания множества деревьев решений.
3. **Преимущества CNN?** CNN автоматически извлекает признаки, учитывает локальность и пространственную структуру, использует общие веса свёрточных ядер и обычно лучше подходит для изображений, чем работа с плоскими пиксельными векторами.
4. **Что такое confusion matrix?** Таблица соответствий истинных и предсказанных классов. Диагональ показывает правильные ответы, остальные клетки — типы ошибок.
5. **Какие метрики используются кроме Accuracy?** Precision, Recall, F1-score, ROC-AUC, а для многоклассовых задач также macro-, micro- и weighted-усреднения.
