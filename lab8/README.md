## Теория

### Сегментация

Сегментация разбивает изображение на области с общими свойствами: яркостью, цветом, текстурой или принадлежностью к объекту. В бинарной сегментации каждый пиксель получает один из двух классов: фон или объект.

### Фиксированный порог

При глобальной пороговой обработке пиксель относится к объекту, если его яркость не меньше `t`:

$$B(x,y)=\begin{cases}255,&I(x,y)\ge t\\0,&I(x,y)<t.\end{cases}$$

В ноутбуке используется `t=180`. Метод прост и быстрый, но требует ручного выбора и плохо работает при неравномерном освещении.

### Метод Отсу

Отсу перебирает возможные пороги и выбирает тот, который максимизирует межклассовую дисперсию:

$$\sigma_b^2(t)=w_0(t)w_1(t)[\mu_0(t)-\mu_1(t)]^2.$$

Он особенно удобен, когда гистограмма имеет два выраженных класса. В коде:

```python
otsu_threshold, otsu_mask = cv2.threshold(
    image, 0, 255,
    cv2.THRESH_BINARY + cv2.THRESH_OTSU
)
```

Для данной картинки Отсу выбрал порог `141`.

### K-means

K-means группирует пиксели по расстоянию до центров кластеров. Алгоритм чередует два шага: назначает пиксели ближайшему центру и пересчитывает центры как средние значения своих кластеров. В работе используется `k=5`, поэтому результат содержит пять уровней яркости.

```python
compactness, labels, centers = cv2.kmeans(
    pixels, 5, None, criteria, 10,
    cv2.KMEANS_PP_CENTERS
)
```

K-means не знает семантики «объект» и «фон»: кластеры — это группы признаков, а не обязательно готовые классы объектов.

### SVM для пиксельной сегментации

Для SVM каждый пиксель рассматривается как отдельный объект. В лабораторной используются признаки:

- нормированная яркость;
- нормированная координата `x`;
- нормированная координата `y`.

SVM с RBF-ядром строит нелинейную границу между пикселями объекта и фона. Целевые классы берутся из маски Отсу.

### U-Net на PyTorch

U-Net состоит из encoder, который сжимает изображение и извлекает признаки, и decoder, который восстанавливает пространственный размер маски. Skip connections соединяют признаки одинакового масштаба и помогают сохранять границы объектов.

В ноутбуке реализована небольшая U-Net:

```text
Conv(1 -> 16) -> ReLU -> Conv(16 -> 16)
MaxPool
Conv(16 -> 32) -> ReLU
Upsample
Concatenate с признаками encoder
Conv -> маска
```

Обучение выполняется через `BCEWithLogitsLoss`, Adam и L2 через `weight_decay=1e-4`. Обучающие патчи получают псевдоцели Отсу.

### Метрики

IoU, или Intersection over Union, сравнивает пересечение и объединение двух масок:

$$IoU=\frac{|A\cap B|}{|A\cup B|}.$$

IoU равен `1`, если маски полностью совпадают, и `0`, если они не пересекаются. В этой работе IoU считается относительно маски Отсу, поэтому SVM и U-Net не проходят независимую проверку качества.

## Ответы на контрольные вопросы

1. **Что такое сегментация изображения?** Разделение изображения на области или классы пикселей, например объект и фон.
2. **Чем отличается глобальная и адаптивная бинаризация?** Глобальная использует один порог для всего изображения. Адаптивная вычисляет разные пороги по локальным окрестностям и лучше справляется с неравномерным освещением.
3. **Как работает Watershed?** Изображение трактуется как рельеф высот. Маркеры задают начальные области, а линии водораздела разделяют соседние бассейны, что помогает разделять соприкасающиеся объекты.
4. **Чем K-means отличается от Fuzzy C-means?** K-means жёстко назначает каждый пиксель одному кластеру. Fuzzy C-means хранит степень принадлежности пикселя каждому кластеру, поэтому границы могут быть мягкими.
5. **Какие преимущества у CNN для сегментации?** CNN автоматически извлекают признаки, учитывают локальный и контекстный масштаб, умеют строить сложные нелинейные границы. U-Net дополнительно сохраняет пространственные детали через skip connections.
